# Changelog

All notable changes to this project are documented here.

## 7.0.0 — 2026-08-18

- Renamed the project and extension to Daggerheart.su Companion.
- Kept print-only usage markers and class normalization out of the on-screen review workspace.
- Restored navigable same-origin rule links inside enhanced class cards.
- Migrated the completed Tampermonkey implementation to a Chrome Manifest V3 content script.
- Replaced Tampermonkey storage APIs with same-origin browser storage.
- Limited execution to `daggerheart.su` and `ru.daggerheart.su`.
- Added localized extension metadata and required icons.
- Added validation, reproducible ZIP packaging, and a GitHub Actions build.
- Added privacy, licensing, testing, store-listing, and publishing documentation.
