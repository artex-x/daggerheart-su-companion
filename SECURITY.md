# Security policy

## Supported versions

Security fixes target the latest source and the latest Chrome Web Store release.

## Reporting a vulnerability

Use GitHub Private Vulnerability Reporting at https://github.com/artex-x/daggerheart-su-companion/security/advisories/new. Do not publish an exploitable report in a public issue before a fix is available.

Include the affected extension version, reproduction steps, impacted site origin, and whether the issue can expose or modify local print-queue data.

## Security boundaries

The extension intentionally uses no remote executable code, background service, privileged Chrome storage, tab access, or all-sites permission. A change to those boundaries requires an explicit security and privacy review.
