# Store artwork checklist

Do not submit placeholder or outdated screenshots. Capture the packaged release in a clean Chrome profile with the Tampermonkey script disabled.

Recommended screenshot set:

1. Ratings and a concise explanatory popover on a normal card catalog.
2. Redesigned class cards in Russian or English.
3. Rating filtering with a clear ancestry or subclass match explanation.
4. The three-column print workspace with real card previews and rearrangement controls.
5. A mixed-ancestry card showing both selected feature texts.

Use the dimensions and promotional-image requirements currently displayed by the Chrome Web Store dashboard. Crop out personal browser data, unrelated tabs, downloads, and developer tools. Do not imply official affiliation in captions or artwork.

The `icons` directory contains the runtime extension icon. Replace it before release if you commission a final identity; rerun `scripts/validate.ps1` after any icon change.
