## English

**Name**

Daggerheart.su Companion

**Summary**

Ratings, improved class cards, filters, and local A4 print preparation for Daggerheart.su.

**Detailed description**

Daggerheart.su Companion improves character-building reference cards on Daggerheart.su without replacing the site.

Use community ratings and contextual comments to compare supported cards, filter catalogs by rating, and view class cards in a denser, consistent format. Add printable cards from supported sections to a local workspace, arrange them in a 3×3 A4 layout, create a mixed-ancestry card from two selected features, and print only the game cards—without ratings or extension controls.

The extension works in English and Russian. Selections and preferences stay in your browser. It has no analytics, ads, account system, or developer server.

This is an unofficial community project. It is not affiliated with or endorsed by Darrington Press or Daggerheart.su. Ratings reflect a third-party author's subjective assessment, not official game guidance.

## Single purpose

Enhance Daggerheart.su character-card browsing and local print preparation with ratings, filters, improved layouts, and a card-selection workspace.

## Host-access justification

The extension runs a static content script only on `daggerheart.su` and `ru.daggerheart.su`. Access is required to read the card DOM, add ratings and filters, restyle class cards, obtain same-origin class-feature text, and assemble user-selected cards for local printing. The extension does not request access to any unrelated website.

## Data-use disclosure notes

- Website content is processed locally to identify and render cards.
- Card selections, ordering, mixed-ancestry names/features, and the rating-filter preference are stored locally in the site's browser storage.
- No data is transmitted to the extension developer.
- No data is sold, used for advertising, credit decisions, or unrelated purposes.
- The extension does not collect browsing history; it runs only on the two declared site origins and does not retain navigation logs.
- A Google Docs ratings-guide link is opened only after an explicit user action.

Use the dashboard's current definitions when selecting disclosure checkboxes. Local processing still needs to be disclosed accurately.
